# Solución al Desafío de Frontend Mentor: Landing Page de Huddle con Secciones Curvas

![Badge](https://img.shields.io/badge/Estado-Completado-brightgreen)  
Este es mi solución al desafío **Huddle Landing Page with Curved Sections** de Frontend Mentor. El objetivo era crear una landing page estática y responsiva con secciones curvas, utilizando **HTML**, **CSS** y **SASS**.

**Desafío de Frontend Mentor:** [Huddle Landing Page](https://www.frontendmentor.io/challenges/huddle-landing-page-with-curved-sections-5ca5ecd01e82137ec91a50f2)  
**Live Demo:** [Ver Proyecto en Vivo](https://omargarcia21.github.io/landing-page-curved.github.io/)

## Descripción del Proyecto

Este proyecto es una landing page estática que presenta información sobre un servicio ficticio llamado **Huddle**. La página incluye:

- Un **header** con un diseño atractivo y un menú de navegación.
- Varias **secciones curvas** que combinan texto e imágenes para describir los beneficios del servicio.
- Un **footer** con enlaces útiles y redes sociales.

El diseño es completamente responsivo, utilizando **CSS Flexbox** y **CSS Grid** para organizar los elementos de manera eficiente y visualmente atractiva. Además, se utilizó **SASS** para modularizar y organizar los estilos.

## Tecnologías Utilizadas

- **Lenguajes de Programación**: HTML, CSS.
- **Preprocesador CSS**: SASS para una gestión más eficiente de los estilos.
- **Metodologías CSS**: Flexbox y Grid para la disposición de los elementos.
- **Diseño Responsivo**: Compatible con dispositivos móviles, tablets y desktop.

## Instrucciones de Instalación y Uso

Este proyecto es una página web estática, por lo que no requiere instalación.
